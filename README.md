# ML Algorithms From Scratch

A collection of Machine Learning algorithms implemented from scratch using Python and NumPy.

The goal of this repository is to understand the **mathematics, intuition, and implementation** behind common ML algorithms rather than relying entirely on high-level libraries.

## 🎯 Goals

- Understand the mathematics behind ML algorithms
- Implement algorithms from first principles
- Derive loss functions and gradients
- Understand optimization techniques
- Compare implementations with `scikit-learn`
- Build a strong foundation for ML interviews

## 📚 Learning Approach

For each algorithm:

1. Understand the intuition
2. Derive the mathematical formulation
3. Implement it from scratch
4. Test it on a small dataset
5. Visualize the results where applicable
6. Compare with a standard library implementation
